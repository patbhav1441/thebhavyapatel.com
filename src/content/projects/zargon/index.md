Zargon is documented as a research project rather than a claim of a fully autonomous or shipped system.

The project is a place to examine how agents can plan and coordinate work across interfaces while remaining observable, interruptible, and constrained. Architecture details and demonstrations will be added only when they can be verified from implementation artifacts.
