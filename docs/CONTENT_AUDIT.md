## Broken-link and placeholder inventory

- `https://www.youtube.com/embed/VIDEO_ID_2` — invalid placeholder, removed.
- General GitHub profile used as project-specific destination — not technically broken, but misleading as a project link; omitted.
- Apex and `www` both previously returned a page instead of enforcing one canonical host — canonical redirect remains a cutover task.
